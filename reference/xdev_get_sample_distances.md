# Get distances between samples in your \`[strollur object](https://mothur.org/strollur/reference/strollur.html)

Get distances between samples in your
[`strollur::strollur`](https://mothur.org/strollur/reference/strollur.md)
object

## Usage

``` r
xdev_get_sample_distances(data)
```

## Arguments

- data:

  a [strollur
  object](https://mothur.org/strollur/reference/strollur.html)

## Value

Rcpp::DataFrame with 3 columns (sample1, sample2, distance)
